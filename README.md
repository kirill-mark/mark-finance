# Mark Finance

Личный финансовый инструмент: учёт приходов и расходов — личных и бизнеса — с остатком на счетах и прогнозом движения денег.

## Что умеет

- **Приходы и расходы** с разделением на «Личное» и «Бизнес», статусами «Ожидается / Получено» и «Запланировано / Оплачено».
- **Регулярные платежи** — зарплата, аренда, ретейнер, налоги: вносятся один раз с повтором каждый месяц или квартал.
- **Остаток сейчас** — от указанных остатков на счетах плюс полученные приходы минус оплаченные расходы.
- **Прогноз остатка** на конец каждого месяца с учётом ожидаемых денег и запланированных трат.
- **Кассовый разрыв** — предупреждение, если прогнозный остаток уходит в минус в ближайшие полгода.
- **Итоги по месяцам, кварталам и году**: приход, расход, чистыми, маржа, сравнение с прошлым кварталом.
- **Ближайшие движения** на 30 и 90 дней, просроченные поступления и платежи.
- **Структура**: откуда приходят деньги и куда уходят.
- **Экспорт в Excel (CSV)**, резервная копия и восстановление (JSON).

## Как запустить

Открыть `index.html` в браузере — сборка и сервер не нужны. Можно включить GitHub Pages (Settings → Pages → ветка `main`, папка `/`) и открывать по ссылке.

Данные при таком запуске хранятся **в этом браузере** (localStorage). Регулярно делай «Резервную копию» внизу страницы — ею же можно перенести данные в другой браузер.

Та же страница опубликована как артефакт на claude.ai — там данные хранятся в облаке и доступны с любого устройства.

## Структура

```
src/app.html   исходник приложения (HTML + CSS + JS в одном файле)
index.html     собранная самостоятельная страница — не редактировать руками
build.sh       собирает index.html из src/app.html
```

После правок в `src/app.html`:

```sh
./build.sh
```

## Данные

Каждая запись:

| Поле | Значение |
|---|---|
| `kind` | `income` — приход, `expense` — расход |
| `scope` | `personal` или `business` |
| `status` | `pending` — ожидается, `done` — проведено |
| `date` | `ГГГГ-ММ-ДД` |
| `amount` | сумма, всегда положительная |
| `title`, `source`, `category`, `note` | описание, контрагент, категория, заметка |
| `seriesId` | общий id у платежей одной регулярной серии |

Настройки: валюта и остатки на счетах на дату (`opening: {date, personal, business}`).
